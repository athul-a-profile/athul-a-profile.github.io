LibGuides Optimization

Reviewed, cleaned, and improved guide content to make library web pages easier to maintain, navigate, and reuse.

Project Overview

This project focused on improving LibGuides quality by reviewing active and inactive guides, checking usage patterns, and identifying content that needed cleanup or reorganization.

Work Done

  • Reviewed guide usage and identified outdated pages.
  • Removed inactive, duplicate, and test content.
  • Improved content organization and naming consistency.
  • Supported cleaner access to library help materials.

My Role

I assisted with content review, cleanup planning, guide organization, and quality checks for a more reliable user experience.

Outcome

The cleanup made the guide environment easier for users to browse and easier for library staff to maintain over time.
