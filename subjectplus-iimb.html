Project Overview & Objective

As part of the Digital Library Team at IIM Bangalore Library, I am working on the deployment, customization, and guide creation for SubjectPlus — an open-source, web-based content management system purpose-built for library subject guides, database directories, and researcher discovery portals.

The objective of this initiative is to expand IIM Bangalore's digital research ecosystem by offering intuitive, subject-specific entry points into the library’s extensive electronic databases, journals, and analytical tools. By installing and customizing SubjectPlus on the institute's server infrastructure, the library is establishing an agile, customizable platform that complements existing digital services and enhances user self-sufficiency.

What Has Been Done

  • Server Deployment: Successfully installed and configured SubjectPlus on IIM Bangalore's Linux server environment running Apache, MySQL/MariaDB, and PHP.
  • System Customization: Custom-tailored the visual theme, typography, header branding, and layouts to ensure seamless visual harmony with the IIM Bangalore Library web identity.
  • Database & User Setup: Configured administrative permissions, staff workflows, and initial taxonomy structures.
  • Guide Structuring & Content Creation: Commenced the structured creation of subject guides, database access pathways, and specialized resource collections for management scholars.

Ongoing Work & Expected Impact

  • Discipline-Specific Taxonomy: Developing dedicated guides across core IIMB academic areas including Economics, Finance, Marketing, Strategy, and Public Policy.
  • Resource Integration: Cataloging subscribed electronic databases into searchable A–Z resource lists with direct access links.
  • User Education & Discovery: Embedding tutorials and search tips to improve information literacy and maximize return on digital library subscriptions.
  • Team Workflow Standardization: Documenting operational steps for ongoing guide maintenance and collaborative staff contribution.
