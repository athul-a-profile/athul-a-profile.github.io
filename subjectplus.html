Library Web Application Project

SubjectPlus Installation

Installed and explored SubjectPlus as a subject guide management platform for organizing library resources, guides, and web-based support content.

Project Overview

The project focused on testing SubjectPlus for library subject guide creation and resource discovery. The setup helped evaluate how a library can organize databases, links, librarian profiles, and subject-based learning materials in one structured platform.

Tools Used

SubjectPlus, XAMPP, Apache, MySQL, PHP, browser-based configuration, local server testing, and basic web customization.

My Role

  • Installed and configured SubjectPlus in a local server environment.
  • Created sample guide structures, menus, and resource links.
  • Tested customization options and library web integration possibilities.

Outcome

The project improved practical understanding of subject guide platforms and their role in digital information services, especially for research support and user-centered resource access.
