Digital Library Repository Project

DSpace Repository Setup & Customization

Configured, customized, and managed institutional repositories to archive academic outputs and improve open-access scholarly communication.

Project Overview

This project focused on configuring DSpace institutional repository software to help academic institutions organize, store, and preserve their digital research outputs (thesis, faculty publications, preprints). The platform enables advanced indexing, search options, and globally accessible repositories.

Focus Areas & Tools

  • Dublin Core metadata element sets configuration.
  • Community and collection hierarchy layout design.
  • Custom submission workflows and license settings.
  • Tools: DSpace, PostgreSQL, Apache Tomcat, Solr, Linux environment.

My Role

  • Configured community structure and collection mappings for faculty publications.
  • Standardized Dublin Core metadata fields for higher cataloging accuracy.
  • Tested PDF indexing, search configuration, and deposit workflows.
  • Set up OAI-PMH harvest testing for repository interoperability.

Outcome

The customized DSpace environment provides a stable, search-engine-friendly repository. It enhances research impact by making research articles discoverable by search systems like Google Scholar.
