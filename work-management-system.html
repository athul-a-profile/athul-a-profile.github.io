Library Work Management System

Custom Full-Stack Web Application for Internal Task Tracking, Workflow Approvals, Role Management & Operational Reporting

• In Production PHP & MySQL IIM Bangalore Workflow Automation RBAC & Auditing Linux Server

Executive Overview & Purpose

At academic and research institutions like IIM Bangalore, library operations involve multifaceted workflows spanning acquisition, digital platform maintenance, patron support, e-resource trials, cataloging routines, and administrative coordination. Relying on fragmented emails, verbal handoffs, or static spreadsheets often creates tracking blind spots and communication bottlenecks.

To resolve these operational challenges, I developed a custom Work Management System (WMS) tailored specifically to the operational architecture of the IIM Bangalore Library. Built from the ground up using PHP and MySQL/MariaDB, the platform centralizes internal task delegation, automates recurring maintenance schedules, handles hierarchical approvals, logs full activity histories, and delivers actionable workload analytics to library leadership.

Key Modules & Capabilities

  • Task Assignment & Lifecycle Tracking: Create, categorize, assign, and track time-sensitive operational tasks with priorities, deadlines, and progress states.
  • Role-Based Access Control (RBAC): Multi-tier user permission structure ensuring staff members, sectional team leads, and administrators access relevant actions and datasets securely.
  • Recurring Task Automation: Configurable recurring schedules for routine library work, such as daily stack inspections, weekly database connectivity audits, and monthly usage statistics compilation.
  • Multi-Level Approval Workflows: Formal review and approval chains for resource procurement, administrative requests, and project deliverables before task sign-off.
  • Timestamped Activity Logs & Audit Trails: Comprehensive logging of status transitions, reassignments, comments, and file attachments for operational accountability.
  • Reporting & Productivity Dashboard: Visual dashboards and tabular reports summarizing completion rates, pending backlogs, and team turnaround times.

Technical Architecture & Development

The system was designed with clean relational database structures, high usability, and zero dependencies on expensive proprietary SaaS tools:

  • Backend Development: Built in PHP following clean modular design patterns for routing, authentication, session security, and business logic execution.
  • Database Schema: Normalized MySQL/MariaDB relational database with indexed tables for users, roles, tasks, recurring templates, approvals, comments, and audit logs.
  • Frontend & UI: Semantic HTML5, CSS3, and JavaScript delivering a fast, responsive, and intuitive interface accessible on desktop and mobile browsers.
  • Deployment Environment: Hosted and maintained on the institute’s secure internal Linux server environment with Apache web server.
  • Security & Integrity: Implemented prepared statements for SQL injection prevention, password hashing, CSRF tokens, and strict role validation on all endpoints.

Operational Impact & Value Delivered

The deployment of the Work Management System transformed day-to-day coordination across the IIM Bangalore Library:

  • Complete Operational Visibility: Section heads and administrators now have real-time oversight of pending, active, and completed deliverables across all library verticals.
  • Accountability & Transparency: Every action and task transition is chronologically recorded, eliminating ambiguity regarding task ownership and timelines.
  • Zero Recurring Work Missed: Automated task generation guarantees that periodic maintenance, compliance tasks, and subscription checks are triggered on schedule.
  • Streamlined Institutional Reporting: Automated analytics eliminate the need for manual data gathering during quarterly reviews and annual library reports.
