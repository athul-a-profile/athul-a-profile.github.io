Creative Outreach Project

Library Promotional Designs

Designed posters, pamphlets, handouts, and display materials to improve library outreach, awareness, and engagement.

Project Overview

This project brought together communication design and library service promotion. The goal was to create simple, useful, and visually clear materials for users.

Materials Created

  • Kindle awareness posters and promotional materials.
  • Resource handouts and user support pamphlets.
  • Thematic book display materials.
  • Guides for e-resources, journal finders, and database pages.

My Role

I prepared content, shaped layouts, organized service information, and created materials that could be used for library outreach and user education.

Outcome

The designs helped communicate library services more clearly and supported stronger user engagement with resources, tools, and events.
