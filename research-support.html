Research Support Project

Reference & Plagiarism Support Services

Supported academic integrity and research workflows by configuring tools, organizing user guides, and running citation database support workshops.

Project Overview

This project focused on establishing research support systems that assist students, researchers, and faculty members in citation management and maintaining academic integrity. By utilizing tools like Zotero, Mendeley, and Turnitin, we created a comprehensive reference support service.

Focus Areas & Tools

  • Zotero and Mendeley database importing, exporting, and citation generation.
  • Turnitin account creation, class enrollment, and similarity report analysis.
  • Scholarly citation styles compliance (APA, MLA, Chicago, Harvard).
  • Research support documentation and self-paced video tutorials.

My Role

  • Created user guides and cheat-sheets for exporting metadata from library catalogs to Zotero/Mendeley.
  • Assisted researchers with Turnitin similarity index troubleshooting and class setups.
  • Organized quick reference handouts on formatting guidelines and plagiarism prevention.
  • Addressed daily reference queries regarding databases and journal finder navigation.

Outcome

The research support workflows reduced citation errors, improved reference collection speed for active researchers, and lowered academic plagiarism rates through proactive user education.
